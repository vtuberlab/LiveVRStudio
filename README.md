# LiveVR Studio

LiveVR Studio は、VRM 形式のモデルを表示し、配信や動画収録に使える VTuber 向けのアプリケーションです（Windows / macOS）。

## 作成者向けマニュアル

モデルを作成する方向けのマニュアルは、このリポジトリの Wiki にあります。

- [LiveVR 作成者向けマニュアル](https://github.com/vtuberlab/LiveVRStudio/wiki)

対応形式や制限、表情や揺れ物の前提など、モデルを作るときに知っておくとよい仕様をまとめています。

## 配信ツール連携

Streamer.bot から LiveVR Studio を操作する手順（Twitch のチャンネルポイント引換で表情・背景を切り替えるなど）は、次の手順書にあります。

- [Streamer.botからLiveVR Studioを操作する](docs/streamerbot-guide.md)
