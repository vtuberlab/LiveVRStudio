# LiveVR Studio

LiveVR Studio は、VRM 形式のモデルを表示し、配信や動画収録に使える VTuber 向けのアプリケーションです（Windows / macOS）。

## 作成者向けマニュアル

モデルを作成する方向けのマニュアルは、このリポジトリの Wiki にあります。

- [LiveVR 作成者向けマニュアル](https://github.com/VTuber-Lab-dev/LiveVRStudio/wiki)

対応形式や制限、表情や揺れ物の前提など、モデルを作るときに知っておくとよい仕様をまとめています。

## 公式サイト

- [VTuber Lab](https://vtuber-lab.jp/)

## このリポジトリについて

このリポジトリは、マニュアル公開用のリポジトリです。LiveVR Studio 本体のソースコードは公開していません。
